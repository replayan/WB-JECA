# 📘 Machine Learning – MCQs with Answers

---

### **1. What is overfitting in machine learning?**

* A) When the model is too simple
* ✅ **B) When the model is too complex**
* C) When the model is not trained enough
* ✅ **D) When the model is trained too much on the training data**

> **Correct Answer:** B and D
> **Explanation:** Overfitting occurs when a model is too complex or trained excessively on training data, capturing noise instead of general patterns.

---

### **2. Which of the following algorithms is an example of the ensemble learning algorithm?**

* ✅ **A) Random Forest**
* B) Decision Tree
* C) Neural Network (NN)
* D) Support Vector Machine (SVM)

> **Correct Answer:** A
> **Explanation:** Random Forest is an ensemble of decision trees, combining their outputs to improve accuracy and prevent overfitting.

---

### **3. Which of the following is a commonly used optimization algorithm for training neural networks?**

* ✅ **A) Gradient Descent**
* B) K-means
* C) Random Forest
* D) SVM

> **Correct Answer:** A
> **Explanation:** Gradient Descent adjusts weights in neural networks to minimize loss. Others are not optimization algorithms for neural nets.

---

### **4. Decision trees can handle\_\_\_\_\_\_\_\_\_**

* ✅ **A) High dimensional data**
* B) Low dimensional data
* C) Medium dimensional data
* D) None of these

> **Correct Answer:** A
> **Explanation:** Decision trees can handle datasets with many features and select the most relevant ones during training.

---

### **5. Temperature is a:**

* ✅ **A) Interval data**
* B) Ratio data
* C) Discrete data
* D) None of the above

> **Correct Answer:** A
> **Explanation:** Temperature in Celsius or Fahrenheit is interval data—it has meaningful differences but no true zero.
